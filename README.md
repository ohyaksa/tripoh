TripOh 1.0

개인과 가족, 친구들이 함께 사용하는 여행 일정 관리 웹 애플리케이션입니다.

프로젝트 정보

- 프로젝트명: TripOh 1.0
- 웹 호스팅: GitHub Pages
- 데이터베이스: 신규 Firebase 프로젝트 및 Firestore 예정
- 기존 프로그램: group-trip-app Ver 1.5

개발 원칙

1. 기존 "group-trip-app" 사이트와 데이터는 보존합니다.
2. TripOh 1.0은 별도의 저장소와 신규 Firebase 프로젝트를 사용합니다.
3. 기존 여행 데이터를 자동으로 이전하지 않습니다.
4. 그룹 기능과 보안을 먼저 설계하고 검증합니다.
5. 기능별 개발과 테스트를 단계적으로 진행합니다.
6. 검토 및 승인 없이 기존 사이트, 데이터 또는 배포 환경을 변경하지 않습니다.

개발 상태

현재 프로젝트 사전 설계 단계입니다.

- [ ] 기존 프로그램 분석
- [ ] 요구사항 명세 작성
- [ ] 그룹 및 보안 설계
- [ ] 데이터베이스 설계
- [ ] 폴더 구조 설계
- [ ] 기능 구현 및 테스트
- [ ] 배포 준비 및 검증

보안 주의사항

비밀번호, 인증 코드, Firebase 서비스 계정 비밀키 및 기타 비밀 정보는 이 저장소에 올리지 않습니다.
